# 台灣軌道動態系統

線上版：<https://ctyangthu.github.io/rail-live/>

把台灣高鐵、臺鐵與五個捷運系統、三條輕軌放在同一張台灣地圖上，依時刻表推算每一班列車現在的位置，並可跨系統查詢轉乘。高鐵與臺鐵部分源自[台灣高鐵動態系統](https://ctyangthu.github.io/thsr-live/)與[台鐵環島動態系統](https://ctyangthu.github.io/tra-live/)，捷運與輕軌部分與[台灣捷運動態系統](https://ctyangthu.github.io/metro-live/)相同。

| 系統 | 路線 | 班次資料 |
| --- | --- | --- |
| 台北捷運 | 淡水信義線、松山新店線、中和新蘆線、板南線（含新北投、小碧潭支線） | 各站時刻表，重建逐班列車 |
| 台北捷運 | 文湖線 | **只有班距**，班次為推估；各站首末班車對齊官方 |
| 新北捷運 | 環狀線、三鶯線 | 各站時刻表，重建逐班列車 |
| 新北捷運 | 淡海輕軌（往崁頂、往淡水漁人碼頭） | **新北捷運官網**各站時刻表（TDX 版已過時），重建逐班列車 |
| 新北捷運 | 安坑輕軌 | 各站時刻表，重建逐班列車 |
| 桃園機場捷運 | 直達車、普通車 | 各站時刻表，重建逐班列車 |
| 臺中捷運 | 綠線（烏日文心北屯線） | **只有班距**，班次為推估；各站首末班車與班距依臺中捷運官網 |
| 高雄捷運 | 紅線、橘線 | 各站時刻表，重建逐班列車 |
| 高雄捷運 | 高雄環狀輕軌（順時針、逆時針） | 各站時刻表，重建逐班列車 |
| 台灣高鐵 | 全線 | 官網時刻表（與 rail-live 相同） |
| 臺鐵 | 全車種 | 臺鐵公司開放資料，每日公告時刻（與 rail-live 相同） |

共 14 條捷運與輕軌路線、288 個車站（同名轉乘站合併後 266 個），平日約 5,400 班列車。

## 功能

- **依日期與星期套用班表**
  - 高鐵：依〈2026/2/2 起適用時刻表〉按星期套用，每日固定 131 班，其餘只在指定星期行駛（一 156、二 149、三 149、四 158、五 179、六 161、日 182）。疏運期間改用另行公告的時刻表，目前收錄〈2026 選舉疏運時刻表〉（11/27–11/30，各日 205、171、192、160 班；11/27 含另行公告的 10 班深夜紅眼班次，標「紅眼」，最晚 01:59 抵達）。時間軸拉到翌日 02:20，跨夜的列車可在原日期看到底。
  - 臺鐵：使用臺鐵每日公告的時刻表（約未來 60 天），每天約 900 班，其中區間車約 680 班、自強號約 130–160 班；超出公告範圍的日期，暫以最近一個同星期的日期推算。
  - 概況卡的「一週班次」分列週一到週日兩鐵各日班次（兩列比例尺不同），點選即可切換日期；疏運日另外標示。
- **即時與模擬**：預設使用台灣現在時間；可切換日期、拖曳時間軸，並以 1×–900× 播放。跨午夜仍在行駛的前一天列車會繼續顯示。
- **地圖**：預設為全島，另有高鐵全線、雙北、機捷、臺中、高雄、東部等範圍。高鐵為橘色路線與方形車站，臺鐵為黑白相間的鐵路符號、支線為虛線，捷運與輕軌依各線代表色。雙鐵列車靠左、捷運靠右行駛，車頭朝行進方向，虛框表示停靠中；點選列車會標出全程路線。區間車與區間快車畫得較小並位於城際列車下方，捷運列車在放大到城市範圍後才顯示。
- **車種與路線篩選**：圖例可逐一顯示或隱藏高鐵、臺鐵各車種與每一條捷運、輕軌路線（例如只看高鐵與自強號），地圖、統計、看板、轉乘查詢與時刻表一起套用；全日在線列車數依車種堆疊。
- **運行中**：此刻在線上的列車，依高鐵、臺鐵、捷運分組。
- **轉乘查詢**：任選高鐵站、臺鐵車站（含支線）或捷運、輕軌車站，跨系統找出直達與轉乘行程，最多搭 4 班車。只保留沒有其他行程更晚出發又更早抵達的選項，每多轉乘一次至少要早 10 分鐘。同一站內換車預留 5 分鐘；捷運的轉乘點見下方「轉乘」，高鐵與臺鐵之間的轉乘點與估計時間：

  | 高鐵站 | 臺鐵站 | 估計 | 方式 |
  | --- | --- | --- | --- |
  | 南港、台北、板橋 | 同名站 | 10–12 分 | 同站轉乘 |
  | 新竹 | 六家 | 8 分 | 車站相連 |
  | 苗栗 | 豐富 | 8 分 | 車站相連 |
  | 台中 | 新烏日 | 10 分 | 車站相連 |
  | 台南 | 沙崙 | 8 分 | 車站相連 |
  | 左營 | 新左營 | 10 分 | 車站相連 |
  | 嘉義 | 嘉義 | 40 分 | BRT 接駁 |

  高鐵桃園、彰化、雲林附近沒有相連的臺鐵車站，未列入轉乘點。
- **列車詳情**：車種與車型說明、停靠與通過車站、可轉乘站、下一站、估算時速；高鐵顯示行駛星期或疏運日期，臺鐵顯示車廂設施、60 天行駛日曆與臺鐵備註。
- **車站看板**：選一站（含支線車站與捷運站）即顯示該站各系統、各方向接下來的班次；同名轉乘站（例如台北車站的板南線與淡水信義線）一起顯示，並可一鍵跳到轉乘的另一站。
- **時刻表**：高鐵為站別時刻矩陣（南下／北上、只列本日行駛），臺鐵為班次列表（順逆行、路線含支線、車次搜尋），捷運依路線與方向列出當日班次。

## 捷運資料怎麼來的

來源是交通部 [TDX 運輸資料流通服務](https://tdx.transportdata.tw/)的 `Rail/Metro` 開放資料。

**有各站時刻表的路線**：TDX 只公布「每一站往各終點的發車時刻」，沒有逐班列車，所以 `tools/build_metro.py` 把它重建成列車：從一個發車時刻出發，下一站取最接近預期行車時間的那個時刻，同一路線的列車不會互相超車。終點站沒有發車時刻，到站時間用最後一站的時刻加上站間行車時間。區間車（例如板南線亞東醫院—南港展覽館、淡水信義線北投—大安）與支線都各自重建。

**只有班距的路線**（文湖線、臺中捷運綠線）：TDX 沒有這兩條線的時刻表，只有各時段的班距範圍、首末班車時間與站間行車時間。本系統從首班車開始，以各時段班距範圍的中間值排出班次，一直排到末班車。這些班次是**推估**，不是實際發車時刻，畫面上會標示。

- 班表依星期區分（平日／假日，高雄捷運另分週五、週六、週日），國定假日未另外處理。
- 捷運列車沒有公開的車次編號，畫面上以路線簡稱代替（文湖、淡信、松新、中蘆、板南、環狀、三鶯、直達、普通、綠線、紅線、橘線）。
- 路線以車站間的直線連接，未使用實際軌道線形。
- 淡水信義線廣慈/奉天宮—象山這一站間 TDX 尚無行車時間，暫以 2 分鐘計。
- 淡海、安坑輕軌沒有公布站間行車時間，重建時以站距估計（每公里約 3.2 分鐘）作為比對基準，實際時刻仍取自各站時刻表。
- 高雄環狀輕軌起訖都在籬仔內，一班車繞行一圈約 90 分鐘，分順時針、逆時針兩個方向。
- 時刻表偶有錯亂的車站。重建時一班車最多可跨過 2 個比對不上的車站再接回，中間的停站時刻依行車時間內插（機場捷運除外：它的跳站車本來就不停那些站）。

## 與官網時刻表的核對

2026/11/21 用 `tools/fetch_official.py` 下載各公司官網的時刻表，`tools/check_official.py` 逐站、逐方向、逐日別（週一、週五、週六、週日）比對：

| 路線 | 官方來源 | TDX 與官方 | 網站顯示的班次與官方 |
| --- | --- | --- | --- |
| 台北捷運 板南、淡水信義、松山新店、中和新蘆線 | 台北捷運各站時刻表 PDF（115.8.30 生效） | 100% 相同 | 100% 相同 |
| 桃園機場捷運 | 桃園捷運各站時刻表（下週一、五、六、日） | 100% 相同 | 100% 相同 |
| 高雄捷運 紅線、橘線 | 高雄捷運各站時刻表（平常日、假日前一日、週六、週日） | 100% 相同 | 100% 相同 |
| 高雄環狀輕軌 | 高雄捷運輕軌各站時刻表（平常日、假日） | 100% 相同 | 100% 相同 |
| 淡海輕軌 | 新北捷運各站發車時刻（.odt） | 約 10%：TDX 是舊班表 | 平日 99.5%、假日 98% |
| 文湖線 | 台北捷運各站首末班車（圖片；與 TDX 首末班表逐一相符） | 只有班距 | 各站首末班 184 項全部相符 |
| 臺中捷運綠線 | 臺中捷運各站首末班車與班距 | 只有班距 | 各站首末班 136 項全部相符 |

修正的內容：

- **淡海輕軌**改用新北捷運官網的時刻表。官網檔案有兩處問題已在程式中處理：淡金北新等站把部分往淡水漁人碼頭的班次寫成往崁頂（依前後站的時刻推回正確終點）；台北海洋大學站往淡水漁人碼頭的假日表仍是舊版（改用濱海沙崙站的時刻加 3 分鐘）。
- **文湖線、臺中捷運**原本只從端點站依班距發車，首班車在中途站最多晚了 38 分、末班車早了 10 分以上。現在每站的首末班車都對齊官方：早上 06:00 有多列車從沿線各站同時發車，深夜也有從中途站發出的末班車；末班車沿線各站時刻依官方首末班表，臺中捷運的班距改用官網公告（尖峰 5–8、離峰 8–10、23 時後 10–20 分）。
- **機場捷運**的尖峰跳站普通車（A21 之後直接停 A18、A13）不再被補上 A20、A19 等停靠站。

沒有官方資料可核對的：環狀線、三鶯線、安坑輕軌（新北捷運官網只有圖片），台北捷運的新北投、小碧潭支線（官網 PDF 無法讀取文字），這些仍用 TDX。高雄捷運 115.11.14–12.27 假日機動加開的班次沒有固定時刻，未納入。

## 轉乘

- 同一個路網內，不同路線的同名車站視為站內轉乘（台北捷運與新北捷運算同一個路網，例如板橋、大坪林、頂埔、景安、頭前庄）。
- 輕軌與捷運同名的車站也一樣（紅樹林、十四張、哈瑪星）。另外設定的轉乘點：台北車站（北捷 ↔ 高鐵、臺鐵、機捷）、板橋與南港（北捷 ↔ 高鐵、臺鐵）、松山（松山新店線 ↔ 臺鐵）、新埔 ↔ 新埔民生、三重與新北產業園區（機捷 ↔ 北捷、環狀線）、鶯歌車站（三鶯線 ↔ 臺鐵）、高鐵桃園（機捷）、高鐵臺中／新烏日、大慶、松竹（中捷 ↔ 高鐵、臺鐵）、左營、高雄車站、橋頭、岡山（高捷 ↔ 高鐵、臺鐵）、前鎮之星 ↔ 凱旋、愛河之心 ↔ 凹子底、凱旋公園 ↔ 苓雅運動園區（高雄輕軌 ↔ 高捷）、鼓山、美術館、科工館（高雄輕軌 ↔ 臺鐵）。
- 轉乘的步行與等候時間都是估計值。

| 1107 | 普悠瑪 | 普悠瑪（TEMU2000） |
| 1101 | 太魯閣 | 太魯閣（TEMU1000） |
| 1108、1109、110A | 自強 | 推拉式自強（1109 附親子車廂，110A 附自行車車廂） |

## 限制

- 列車位置依時刻表推算，不含誤點等即時資訊；臺鐵車站之間以直線相連。
- 轉乘的步行與等候時間為估計值，BRT 班次未納入。
- 高鐵國定假日與連假另行公告的時刻表，目前只收錄選舉疏運。新的疏運時刻表公告後，以 `tools/parse_thsr_special.py` 加入。
- N700ST 依新聞報導預計 2027 年 7 月 1 日投入營運；本系統以 N700ST 呈現所有高鐵車次。
- 捷運列車位置依表定時刻（文湖線、臺中捷運綠線依班距）推算，不含誤點、停駛等即時營運資訊；TDX 的即時到站資料需要金鑰，靜態網頁無法直接取用。
- 捷運資料只在手動執行 `tools/fetch_metro.py` 與 `tools/build_metro.py` 時更新，目前為 2026/11/11 的資料；臺鐵則每天自動更新。
- 未納入貓空纜車。
- 本系統為非官方展示，實際行車以各公司公告為準。

## 專案結構

```
src/app.html                          網頁原始碼（資料以佔位字串嵌入；捷運部分與 metro-live 相同）
data/thsr-timetable-2026-02-02.json   高鐵一般時刻表：214 個車次與行駛星期
data/thsr-special-2026-11-27.json     高鐵選舉疏運時刻表：228 個車次與行駛日期
data/thsr-extra-2026-11-27-redeye.json  高鐵 11/27 紅眼班次 10 班（與 thsr-live 的 special-2026-11-27-redeye.json 相同）
data/tra-stations.json                臺鐵車站基本資料（代碼、站名、GPS）
data/tra-trains.json                  臺鐵每日時刻表整理出的全車種班表、車站與軌道圖
data/metro.json                       五個捷運系統與三條輕軌的逐班列車（tools/build_metro.py 產生）
data/counties-10t.json, map.json      縣市界 TopoJSON 與投影後的地圖路徑
raw/                                  臺鐵、TDX 捷運與各公司官網時刻表原始資料（不納入版本控制）
tools/parse_thsr_timetable.py         解析高鐵一般時刻表 PDF（需要 pdfplumber）
tools/parse_thsr_special.py           解析高鐵疏運時刻表 PDF（需要 pdfplumber）
tools/fetch_tra_timetable.py          下載臺鐵目前公告的所有每日時刻表 JSON
tools/extract_tra_trains.py           整理全車種班表，並推出軌道相鄰關係（與 tra-live 同步）
tools/fetch_metro.py                  下載 TDX 捷運資料（已下載的檔案會略過）
tools/build_metro.py                  由各站時刻表重建逐班列車；只有班距的路線依班距排班並對齊各站首末班
tools/fetch_official.py               下載各公司官網時刻表與首末班車（與 metro-live 相同）
tools/official.py                     讀取官網時刻表（PDF、HTML、.odt）
tools/check_official.py               比對 TDX／網站班次與官網時刻表
tools/build_map.py                    產生 data/map.json
tools/build.py                        組出 dist/index.html
```

## 建置

```bash
python3 tools/build.py
```

產出的 `dist/index.html` 可直接用瀏覽器開啟。推送到 `main` 後，GitHub Actions 會建置並部署到 GitHub Pages，並在每天 04:30（台灣時間）重新下載臺鐵時刻表。

更新高鐵時刻表：

```bash
python3 tools/parse_thsr_timetable.py 新時刻表.pdf data/thsr-timetable-YYYY-MM-DD.json
python3 tools/parse_thsr_special.py 疏運時刻表.pdf data/thsr-special-YYYY-MM-DD.json "疏運名稱"
python3 tools/build.py
```

`build.py` 取日期最新的 `thsr-timetable-*.json` 為一般時刻表，所有 `thsr-special-*.json` 為疏運期間；`build.py` 的 `THSR_EXTRAS` 把另行公告的加開車次（`thsr-extra-*.json`）併入其行駛日期所屬的疏運期間，並加上標籤與說明。

在本機更新臺鐵時刻表（原始檔約 120 MB，放在 `raw/`，不納入版本控制）：

```bash
python3 tools/fetch_tra_timetable.py raw
python3 tools/extract_tra_trains.py raw data/tra-trains.json
python3 tools/build.py
```
